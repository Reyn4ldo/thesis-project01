# Data Dictionary - AMR Surveillance System

## Overview
This document describes all data fields in the AMR surveillance dataset.

## Metadata Fields

### bacterial_species
- **Type**: Categorical
- **Description**: Bacterial species identification
- **Examples**: 
  - `escherichia_coli`
  - `klebsiella_pneumoniae_ssp_pneumoniae`
  - `enterobacter_cloacae_complex`
  - `enterobacter_aerogenes`

### isolate_code
- **Type**: String (Identifier)
- **Description**: Unique identifier for each bacterial isolate
- **Format**: `{species_code}_{site_code}{source_code}{replicate}c{colony}`
- **Example**: `ec_pgdwr1c2`

### administrative_region
- **Type**: Categorical
- **Description**: Administrative region where sample was collected
- **Examples**: `region_iii_central_luzon`

### national_site
- **Type**: Categorical
- **Description**: National-level geographic location
- **Examples**: `pampanga`

### local_site
- **Type**: Categorical
- **Description**: Local-level sampling site
- **Examples**: `san_gabriel`

### sample_source
- **Type**: Categorical
- **Description**: Source of the bacterial sample
- **Values**:
  - `drinking_water`: Potable water source
  - `river_water`: Surface water from rivers
  - `fish_tilapia`: Fish samples (tilapia)
  - `fish_bangus`: Fish samples (milkfish)

### replicate
- **Type**: Integer
- **Description**: Replicate number for sampling
- **Range**: 1-N

### colony
- **Type**: Integer
- **Description**: Colony number from culture plate
- **Range**: 1-N

### esbl
- **Type**: Categorical
- **Description**: Extended-Spectrum Beta-Lactamase test result
- **Values**: `pos`, `neg`, `NA`

## Antibiotic Susceptibility Testing (AST) Fields

Each antibiotic has two associated fields:
1. `{antibiotic}_mic`: Minimum Inhibitory Concentration (numeric or inequality)
2. `{antibiotic}_int`: Interpretation (S/I/R)

### Interpretation Values
- **S**: Susceptible (encoded as 0)
- **I**: Intermediate (encoded as 1)
- **R**: Resistant (encoded as 2)

### Antibiotic Classes and Agents

#### Beta-Lactams
- `ampicillin`: Broad-spectrum penicillin
- `amoxicillin_clavulanic_acid`: Penicillin with beta-lactamase inhibitor
- `ceftaroline`: 5th generation cephalosporin
- `cefalexin`: 1st generation cephalosporin
- `cefalotin`: 1st generation cephalosporin
- `cefpodoxime`: 3rd generation cephalosporin
- `cefotaxime`: 3rd generation cephalosporin
- `cefovecin`: 3rd generation cephalosporin (veterinary)
- `ceftiofur`: 3rd generation cephalosporin (veterinary)
- `ceftazidime_avibactam`: 3rd generation cephalosporin with inhibitor

#### Carbapenems
- `imepenem`: Carbapenem (broad-spectrum, last-resort antibiotic)

#### Aminoglycosides
- `amikacin`: Aminoglycoside
- `gentamicin`: Aminoglycoside
- `neomycin`: Aminoglycoside

#### Fluoroquinolones
- `nalidixic_acid`: First-generation quinolone
- `enrofloxacin`: Fluoroquinolone (veterinary)
- `marbofloxacin`: Fluoroquinolone (veterinary)
- `pradofloxacin`: Fluoroquinolone (veterinary)

#### Tetracyclines
- `doxycycline`: Tetracycline derivative
- `tetracycline`: Broad-spectrum antibiotic

#### Nitrofurans
- `nitrofurantoin`: Nitrofuran antibiotic (UTI treatment)

#### Phenicols
- `chloramphenicol`: Broad-spectrum antibiotic

#### Sulfonamides
- `trimethoprim_sulfamethazole`: Folate synthesis inhibitor combination

## Derived Fields (Generated by Pipeline)

### Encoded Antibiotic Fields
- **Pattern**: `{antibiotic}_encoded`
- **Type**: Integer
- **Description**: Numeric encoding of S/I/R interpretations
- **Values**: 0 (S), 1 (I), 2 (R)

### scored_resistance
- **Type**: Integer
- **Description**: Original resistance score from data source
- **Note**: Validated against calculated values

### num_antibiotics_tested
- **Type**: Integer
- **Description**: Total number of antibiotics tested for isolate
- **Range**: Variable (typically 19-22)

### mar_index
- **Type**: Float
- **Description**: Original Multiple Antibiotic Resistance index
- **Formula**: (Number resistant) / (Number tested)
- **Range**: 0.0 - 1.0

### mar_index_calculated
- **Type**: Float
- **Description**: Pipeline-calculated MAR index
- **Formula**: (Number resistant) / (Number tested)
- **Range**: 0.0 - 1.0
- **Note**: Used for validation against original values

### num_resistant
- **Type**: Integer
- **Description**: Count of antibiotics with resistant interpretation (R)

### num_tested
- **Type**: Integer
- **Description**: Count of antibiotics tested (non-missing values)

### resistant_classes_count
- **Type**: Integer
- **Description**: Number of antibiotic classes with at least one resistant agent
- **Range**: 0-8

### is_mdr
- **Type**: Binary (0/1)
- **Description**: Multi-Drug Resistant classification
- **Definition**: 1 if resistant to ≥3 antibiotic classes, 0 otherwise
- **Note**: Primary target variable for supervised learning

## Data Quality Notes

1. **Missing Values**: Handled according to documented policy (20% threshold)
2. **Special Markers**: 
   - `*` with S/I/R indicates borderline or special case
   - `≥` or `≤` in MIC values indicate concentration limits
3. **Encoding**: All categorical fields lowercase with underscores
4. **Validation**: MAR index recalculated and validated against original

## Usage in Models

### Features Used
- All `{antibiotic}_encoded` fields
- `bacterial_species_encoded`
- `sample_source_encoded`
- `administrative_region_encoded`
- `num_resistant`
- `num_tested`
- `mar_index_calculated`

### Target Variable
- `is_mdr`: Binary classification (MDR vs Non-MDR)
